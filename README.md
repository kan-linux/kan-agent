## Overview

Kan-Agent (Guanyuan, 观元): The native agent subsystem of Kan-Linux, powered by llama.cpp.

It autonomously builds, deploys, audits, rolls back and troubleshooting system components, replacing traditional package managers and app stores in traditional Linux distributions.

## Description

A core feature of **Kan-Linux is the absence of traditional package managers (apt, dnf, pacman, ...)**. Kan-Agent is an agent-first system orchestrator.
No conventional package manager required. Local inference, reproducible builds, fine-grained permission control, safe rollback.


## Contribution

Kan-Agent is a fully open-source project, similar to project [ggml-hexagon](https://github.com/kan-linux/ggml-hexagon), can be used in other Linux distro.

We build Kan-Agent in the spirit of exploration. Contributors are encouraged to try crazy ideas, build wild demos, and push the edge of what’s possible.

## Language Policy and AI Policy

- To facilitate clear and effective communication, all discussions, comments, documentation, and PRs in this project **should be** conducted in English, this ensures that all contributors can participate and collaborate effectively.
- English and Chinese are **both fine** for issues, discussions.
- Discussions, issues and PRs should include **human-written content**. **AI-assisted polish is accepted and welcomed**(many of us are non-native English speakers). What matters is not who typed the content but whether a human understands it.
- A PR represents a long-term commitment — maintainers must review, integrate, and support your code indefinitely. What matters is not who wrote the code but whether a human understands it: **either fully, or at the 70–90% level, and is able to explain major change to reviewers, even with AI assistance**.
- Fully automated AI-generated content and fully automated PRs are not permitted. We value human connection and communication over fully AI-driven interaction.
